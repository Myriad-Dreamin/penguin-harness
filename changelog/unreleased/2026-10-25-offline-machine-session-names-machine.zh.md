# 离线机器上的对话写出机器名并给出重试

- **Date:** 2026-10-25
- **Type:** fix
- **Scope:** `web`

[English](2026-10-25-offline-machine-session-names-machine.md)

机器失联时，页面写出对话在哪台机器上（别名），显示与「机器管理」页一致的重连状态——第几次、共几次、下一次何时——并提供立即重试。机器恢复后，对话自动打开，无需手动刷新。

## 冷打开深链接

机器失联时打开 `/chat/<session>`，过去只有一句通用提示：机器答不上来的那段时间，侧栏列表没有这个对话的行，页面连机器名都写不出来——而服务器对这次直接查询的 503 恰恰带着机器名和别名。页面现在保留这份回答并据此呈现提示：机器别名、重连状态、一句折叠起来的服务器原文，以及一个让服务器立即重连机器的重试按钮。机器恢复后，查询自动再跑一次，对话原地打开。

## 已经打开的对话

正文已在页面上的对话，机器断线和重连期间毫无提示：它的历史读取发生在机器还能应答的时候，之后没有任何一次失败能替机器说话。对话上方现在有一条提示，写出机器名和同样的重连进度，机器恢复应答后自行消失。
