# 排队中的 run 只在真正服务的那一代启动

- **Date:** 2026-10-20
- **Type:** fix
- **Scope:** `server`

[English](2026-10-20-queued-runs-wait-for-the-serving-generation.md)

一代不再在构造时就接管排队工作的自动启动。它先握着自己的认领，由平台壳在这一代 boot 真正成为现役 App 的那一刻才装上——冷启动、提交成功的重装、失败后的恢复。还处在提交边界之前的候选什么也不启动：换装在半空中时有 run 结束，它排队的后续输入与空闲到达的后台通知都先停住，由最后服务的那一代启动；队列里没有任何东西丢失、被启动两次、或被一个从未服务过的代际启动。

推送装起来的那一代同样先按住——它接过的 slip 上带着现役方的承诺——由开这张 slip 的路由在推送落地后交班。失败的推送恢复上一代，同样把队列接回去。回滚到早于本变更的版本时，那一代照旧在构造时认领，落地后的交班调用在它身上是空操作。
