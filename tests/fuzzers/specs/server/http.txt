# The API surface, described.
#
# One line per route: `METHOD /path(arguments)`. An argument whose name is a `:slot` of the
# path fills that slot; `body` is the JSON body, a struct declared below; every other argument
# is a query knob. A type is a resource (an id the run has collected), `int32[lo:hi]`,
# `enum["a", "b"]`, `bool`, `string` (the input's own bytes) or `array[...]`; a trailing `opt`
# marks an argument a valid call may leave out.
#
# The route list is checked against `specs/surface.json`, which `specs/extract.mjs` reads off
# the product's own declarations: a route the product adds and this file lacks fails
# `specs/generate.ts --check`, and `--draft` prints the line to add. Routes the fuzzer must not
# drive live in `skipped.txt`, with the reason.
