# The CLI surface, described.
#
# One line per command: `a.b.c(arguments) [exits 0,1] [together --x,--y]`. An argument is
# `name type`; one spelled with leading dashes is an option (`-m|--message text`), and the
# rest are positionals, filled in order. A trailing `opt` marks a value a well-formed line may
# leave out; a trailing `never` declares an option this leg does not pass — `--root`, `--server`
# and `--workspace` name where the command works and the leg owns all three, and a command whose
# wait the leg keeps out of the table says why at its own line.
# `exits` lists the codes a valid line may produce — 0,1 unless the command's contract is a
# clean exit. `together` names options that only mean something as a set.
#
# A type decides the value: `text` is the input's own bytes (and marks the slot they land in),
# a resource name draws an id the run has collected, `int32[lo:hi]` draws inside its range,
# `enum[...]` draws a value the product's own validator accepts, `array[T]` repeats one, and
# `string` is free text. No value is chosen by looking at a name: what a command accepts is
# stated here, and a command the text lacks is not run.
#
# The list is checked against the commander tree the CLI itself builds (`specs/cli/tree.ts`):
# a command, argument or option the product adds and this file lacks fails
# `specs/generate.ts --check`, and `--draft` prints the line to add. Commands the leg must not
# drive live in `skipped.txt`, with the reason.

# ---- types this leg's own fixture makes true

# The leg's setup registers one model row (`cli/src/fuzz.ts`): naming it here is what lets a
# call reach the path that uses a model instead of the one that refuses an unknown id.
type fixtureModel enum["fuzz-model"]
type fixtureProvider enum["fuzz-group"]

# `--timeout` accepts `30s`, `5m`, `2h` or a bare integer of seconds (`cli/src/duration.ts`).
type duration enum["0", "1s", "30s", "5m"]
# `--start-at` takes `now` or an ISO 8601 instant (`cli/src/commands/schedule.ts`).
type instant enum["now", "2026-10-01T00:00:00Z"]
# A schedule period looks like `30m` / `12h` / `7d`, with 5m the floor (`packages/server/src/runtime/schedule-file.ts`).
type schedulePeriod enum["30m", "12h", "7d"]
# A goal budget is a positive number with an optional `k`/`m` suffix (`cli/src/goal-command.ts`).
type tokenBudget enum["500k", "1m", "120"]
# The thinking levels core offers (`DEFAULT_CHAT_THINKING_LEVELS`).
type thinkingLevel enum["low", "medium", "high", "xhigh", "max"]
# The approval modes `--approve` accepts (`cli/src/approval.ts`).
type approvalMode enum["allow-all", "deny-all", "read-only", "always-ask"]
